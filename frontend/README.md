# 🌎 Jaboatão 360 — Frontend

Interface web do projeto **Jaboatão 360**, desenvolvida com React + Vite.

---

## 🛠️ Tecnologias e dependências

| Pacote | Versão | Finalidade |
|---|---|---|
| React | 19 | Biblioteca de interface |
| Vite | 6 | Bundler e servidor de desenvolvimento |
| React Router DOM | 7 | Roteamento entre páginas |
| Tailwind CSS | 4 | Estilização utilitária |
| Leaflet | 1.9 | Motor de mapas interativos |
| React Leaflet | 5 | Integração do Leaflet com React |
| Axios | 1.x | Requisições HTTP para a API |
| ESLint | 9 | Análise estática de código |

---

## 📋 Pré-requisitos

- [Node.js](https://nodejs.org) v18 ou superior
- npm v9 ou superior

---

## ⚙️ Instalação e execução

**1. Clone o repositório:**
```bash
git clone https://github.com/Micael-exe/Jaboatao-360.git
cd Jaboatao-360/frontend
```

**2. Instale as dependências:**
```bash
npm install
```

**3. Inicie o servidor de desenvolvimento:**
```bash
npm run dev
```

Acesse em: `http://localhost:5173`
